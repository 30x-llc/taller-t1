# Taller T1 · Claude Code

Carpeta de inicio del Taller T1 de AI for Developers (30X). Con ella construyes un quiz de repaso y pruebas las 4 piezas que configuran Claude Code: `CLAUDE.md`, skills, MCP y hooks.

Guía paso a paso: [Taller T1](https://storage.googleapis.com/xhub-499017-30xhub-programs-content/cohort-content/da2c7344-a974-40b8-9f9b-ca45f6594b21/slides/taller-1/index.html)

## Descarga

```bash
git clone https://github.com/30x-llc/taller-t1.git
cd taller-t1
```

Sin git, descarga [taller-t1.zip](https://github.com/30x-llc/taller-t1/releases/latest/download/taller-t1.zip) y descomprímelo.
